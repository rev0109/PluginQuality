What's wrong:
The plugin class is registered twice in the same file through two different mechanisms (Plugin::Metadata and SERVICE_REGISTRATION). The rule allows SERVICE_REGISTRATION in the main plugin file only for a different class (for example an out-of-process implementation class).

Code found:

// AVOutput.cpp:32

        {}, {}, {});

// AVOutput.cpp:44

Fix:

// Keep exactly one registration for the plugin class
static Plugin::Metadata<Plugin::AVOutput> metadata(
        API_VERSION_NUMBER_MAJOR, API_VERSION_NUMBER_MINOR, API_VERSION_NUMBER_PATCH,
        {}, {}, {});
// SERVICE_REGISTRATION(AVOutput, ...) removed
